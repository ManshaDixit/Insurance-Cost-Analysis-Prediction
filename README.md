# Insurance Cost Analysis & Prediction

This project focuses on analyzing medical insurance data and predicting insurance expenses using Python and Machine Learning.

## 📌 Project Overview

The dataset was explored to understand the factors that influence medical insurance costs. The project includes data cleaning, exploratory data analysis (EDA), statistical analysis, correlation analysis, and feature analysis.

Various visualizations were created using Matplotlib and Seaborn to identify patterns and relationships between features such as age, BMI, smoking status, gender, children, and region.

Statistical techniques including Pearson correlation and Chi-Square tests were used to analyze relationships between variables.

Finally, a regression model was developed to predict insurance expenses. The model was evaluated using R² and Adjusted R².

## 📈 Model Evaluation

The regression model was evaluated using:

- R² Score
- Adjusted R² Score

The model achieved an R² score of approximately **70.61%** and an Adjusted R² score of approximately **70.16%**.
